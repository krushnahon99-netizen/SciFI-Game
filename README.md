# ECHO — The World Remembers Everything

An original third-person sci-fi exploration and environmental-puzzle game for the browser, built with
Three.js. Send an **Echo Pulse** through an abandoned alien world to reveal what the stone remembers.

> **Status:** in development. Live progress, architecture and next steps are in [`AGENTS.md`](AGENTS.md).
> The original design brief is in [`docs/GAME_SPEC.md`](docs/GAME_SPEC.md).

## Run locally

Requirements: Node.js 20+ and pnpm.

```bash
pnpm install
pnpm dev        # http://localhost:3000
pnpm build      # production build
pnpm start      # serve the production build
```
